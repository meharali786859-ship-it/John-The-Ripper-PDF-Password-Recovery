# John the Ripper – PDF Password Recovery

## Project Overview
This project demonstrates a practical password recovery exercise using John the Ripper (JTR) and Johnny GUI on Windows.

The objective was to understand PDF hash extraction, password auditing, and the password recovery process.

## Tools Used
- John the Ripper (JTR)
- Johnny GUI
- Windows Operating System
- PDF Hash Extraction Tool

## Practical Workflow
1. Installed John the Ripper and Johnny GUI.
2. Configured Johnny GUI with john.exe.
3. Extracted the hash from a password-protected PDF.
4. Saved the extracted hash in a text file.
5. Imported the hash into Johnny GUI.
6. Started the password recovery process.
7. Successfully recovered the password.
8. Verified the recovered password by opening the PDF.

## Key Learning Outcomes
- PDF password hash analysis
- Password recovery techniques
- John the Ripper configuration
- Johnny GUI usage
- Password security and auditing
